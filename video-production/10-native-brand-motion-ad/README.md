# Tunisiska Mega — Native Brand Motion Ads

Two original, 30-second app ads in Swedish and Arabic. Every scene is drawn from code in the Tunisiska Mega palette and rounded-card design language. There are no app screenshots or recordings.

## Finished masters

- `10-native-brand-motion-ad-sv.mp4` — Swedish, 1080 × 1920, 24 fps.
- `10-native-brand-motion-ad-ar.mp4` — Arabic, 1080 × 1920, 24 fps.
- `sv.srt` / `ar.srt` — localized captions.
- `poster-sv.jpg` / `poster-ar.jpg` — localized preview frames.

The ad covers scheduled trips, parcel and container shipping, moving and cleaning, airport taxi, booking, and shipment tracking. Dates, prices, user information, live capacity and performance promises are not used.

## Rebuild

Run `sh build.sh`. The script uses the shared Lemo-Opuscar library at `/Users/haythem_dhahri/lemo-opuscar`. The bundled Rubik font and OFL license keep the project self-contained; rendering also requires Node, Chromium, Python with NumPy, and FFmpeg.

`TREATMENT.md` records the product analysis, design tokens, claims and creative direction. `CREDITS` identifies the supplied brand materials and original generated assets.
